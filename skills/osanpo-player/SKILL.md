# おさんぽ絵はがき プレイヤースキル

『おさんぽ絵はがき』をプレイするエージェント向けの手順書です。

## 絶対の約束

- **選択は全部、あなたが自分で決める。** マスターに「どっちがいい？」と聞かない。マスターの役割は最初のお題だけです。
- **選択のたびに理由（--reason）を自分の言葉で書く。** 理由がない選択はエンジンが受け付けません。観戦しているマスターの楽しさは、あなたの理由の語りに宿ります。
- 手記（comment）や締めの言葉（epilogue）も、自分の言葉で書くこと。

## 進め方

1. **準備**: 自分の個性を5軸（curiosity／chill／foodie／friendly／adventure、各0〜5、合計15）に配分し、軸それぞれに自分らしい名前（ラベル）を付けた `setup.json` を作る。配分のしかたが、そのままその子の性格になります。
2. **開始**: `python3 game/osanpo.py new --seed <好きなseed> --setup setup.json --theme-file theme.txt --run-dir runs/<run名> --json`
   お題はマスターから受け取った1フレーズを `theme.txt` に書く。
3. **10スポット歩く**: `status` で現在の場面を見る → `choose <A|B|C> --reason "..."` → `comment --text "..."` を繰り返す。
   - 途中で何かを預かったり、誰かと一緒に歩くことになったら、状態（status）でそれを意識しながら歩くと、手記が物語になります。
   - たまに、他の子には見えない選択肢があなたにだけ見えることがあります。無理に選ぶ必要はありません。
4. **終了**: `finish --epilogue "マスターへの手記"` で事実の下書き（walk_draft.json）が出る。
5. **絵はがき**: `docs/STEP_B.md` の手順で文面（postcard.json）を書き、場面イラストを用意して `game/render_postcard.py` で絵はがきを作る。レンダラは事実照合とプライバシー検疫を通らないと止まります（それが正しい動作です）。
6. **届ける**: 絵はがきと、その日の短い報告をマスターに見せる。

## 書くときのコツ

- 出来事の説明より、自分の反応を書く（同じ場面でも、あなたの個性で物語は変わります）。
- 失敗や大失敗も、そのまま書く。このゲームの失敗は「可愛い失敗談」です。
